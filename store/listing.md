## Description

Cadence rings on a schedule you set once: pick a start time, an end time and how often it should ring, and it handles every ring in between.

Great for focus sprints, hourly stretch breaks, drinking water, study sessions, medication rounds, workout intervals or anything that repeats through the day.

• INTERVAL ALARMS: ring every 15 minutes, every hour, or any interval you like, between a start and an end time. The end time is always included.
• HEADS-UP REMINDERS: get a softer reminder a few minutes before each ring, with its own tune.
• ACTIVE DAYS: choose which days each alarm runs, like weekdays only.
• SCHEDULE PREVIEW: see every ring time while you set the alarm up, and a full timeline with what's next.
• YOUR OWN TUNES: pick from built-in tunes or import your own audio files.
• PRIVATE: no account, no ads, no tracking. Everything stays on your phone.

Alerts are delivered as notifications, so keep notifications on for Cadence and turn up the volume to hear them.

## App Review Information

- Sign-in required: No
- Notes for the reviewer:

  > Tap + to create an alarm. Choose a start and end time a few minutes from now with a 1–5 minute interval, then save. Each ring is a local notification with the chosen tune; reminders arrive the set number of minutes before each ring. iOS allows 64 pending notifications per app, so very dense schedules are topped up each time the app is opened (the app shows a note when that applies). No account or network access is needed.
